# Game Hub

Startet und verteilt Spiele im Freundeskreis. Der Hub lädt die Spiele aus diesem Repo und hält sie automatisch aktuell.

## Für Mitspieler
1. ZIP vom Host holen und entpacken.
2. `Game-Hub starten.bat` doppelklicken.
3. Der Hub lädt beim Start alle Spiele und aktualisiert sie bei jeder neuen Version.

## Für den Host (Veröffentlichen)
Siehe `scripts/publish.js`. Spiele werden als GitHub-Release hochgeladen und `catalog.json` aktualisiert.
